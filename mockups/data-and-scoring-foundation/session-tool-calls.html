1. A session with tool calls

Each call sits on the rail between the customer's message and the reply it produced. Collapsed, a passing call is one quiet line. A failed check turns the node red and names the problem in words. Text the agent said before calling stays a normal line. Three or more calls in one turn fold into a group, which opens by itself when one of them failed. Identical repeats fold into ×2.
